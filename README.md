# FinTrack — site vitrine

Exercice d'intégration web réalisé en cours (BTS SIO option SLAM, H3 Hitema, 2025).

Site de présentation d'une application de gestion de budget **fictive** : le produit, les chiffres
et les témoignages affichés sont inventés pour l'exercice. L'objectif était la mise en page et l'intégration.

## Pages

Accueil, Fonctionnalités, Tarifs, Contact (dossier `cours1/`).

## Fonctionnalités

- Filtre des fonctionnalités par catégorie (Budget, Analyse, Sécurité, Mobile)
- Bascule des tarifs entre mensuel et annuel, utilisable au clavier
- Formulaire de contact avec message de confirmation (sans envoi réel : pas de serveur)
- Questions fréquentes en accordéon
- Animations d'apparition au défilement et léger effet de parallaxe

## Technologies

HTML, CSS, JavaScript, Bootstrap 5, Bootstrap Icons.

## Lancer le site

Ouvrir `cours1/index.html` dans un navigateur.
